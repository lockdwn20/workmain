#### `workmain/cli/commands/gdocs.py` v1.0
- `gdocs auth [--reauth]` — runs OAuth flow, caches period folder structure post-auth
- `gdocs status` — shows auth state, cached folders, last 5 uploads from DB
- `gdocs upload-notes [--date YYYYMMDD] [--dry-run] [--force]`
  - Queries DB for notes by `created_date`, formats as markdown (§3.8 format)
  - Writes to `staging/notes/Daily_Notes_YYYYMMDD.md`
  - Uploads to `YYYYMM/Raw_Notes/`; records in `gdrive_uploads`
- `gdocs upload-report [--date YYYYMMDD] [--dry-run] [--force]`
  - Finds `staging/reports/daily_internal_YYYY-MM-DD.md` (hyphenated format — matches `report save` output)
  - Uploads to `YYYYMM/Reports/`
- `gdocs upload-clockify [--date YYYYMMDD] [--dry-run] [--force]`
  - Finds `staging/clockify/Clockify_YYYYMMDD.pdf`
  - Uploads to `YYYYMM/Clockify/`, MIME: `application/pdf`
- `gdocs upload-all [--date YYYYMMDD] [--dry-run] [--force]`
  - Runs upload-notes → upload-report → upload-clockify in sequence
- `_format_notes_markdown(notes, target_date)` — §3.8 format:
  - Header: `# Daily Notes — YYYY-MM-DD`
  - Note sections: `## [tag1] [tag2] HH:MM` (24h time, space-separated brackets)
  - Default tag if none specified: `[internal-only]`
  - Footer: `*Generated by WorkmAIn on <datetime>*`
  - Notes in ascending `created_at` order
- All upload commands use `already_uploaded()` check before every upload (duplicate protection mandatory)
- `GDRIVE_TIMECARDS_ROOT` not set → clear error, no silent default
- Session pattern: `db = get_db(); session = db.get_session()`

    id              SERIAL PRIMARY KEY,
    local_path      TEXT        NOT NULL,

    drive_folder_id TEXT        NOT NULL,
    filename        TEXT        NOT NULL,
    upload_type     TEXT        NOT NULL,

CREATE INDEX idx_gdrive_uploads_date ON gdrive_uploads(upload_date);
CREATE INDEX idx_gdrive_uploads_type ON gdrive_uploads(upload_type);

## DEVIATIONS FROM SPEC (with rationale)

### 1. Report filename uses `YYYY-MM-DD` (not `YYYYMMDD`)
**Spec intent:** `daily_internal_YYYYMMDD.md`
**Delivered:** `daily_internal_YYYY-MM-DD.md`
**Rationale:** `report save` outputs hyphenated format (`report_generator.py:548`). Spec was corrected pre-implementation to match actual output. The `upload-report` command searches for the hyphenated filename.

### 2. `interface.py` registered in Gate 3 (not Gate 4)
**Spec intent:** Register `gdocs` in Gate 4
**Delivered:** Registered in Gate 3 alongside gdocs.py creation
**Rationale:** CLI verification of Gate 3 commands required the registration. No functional difference.
